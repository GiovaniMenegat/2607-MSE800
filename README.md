# 2607-MSE800

This repository stores activities and coursework completed for the **Professional Software Engineering** programme at **Yoobee College**.

## Purpose

Each folder in this repository corresponds to a week (or module) of the programme and contains the exercises, scripts, and small projects completed as part of the coursework.

## Structure

```
2607-MSE800/
└── week1/
    └── bmi-calculator.py   # Simple BMI (Body Mass Index) calculator
```

As the programme progresses, new folders (e.g. `week2`, `week3`, ...) will be added, each containing the activities for that week.

## Running the code

Most activities are standalone Python scripts. To run one, use:

```bash
python3 week1/bmi-calculator.py
```

Follow the on-screen prompts as required by each script.
